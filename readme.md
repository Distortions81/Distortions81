# Carl Otto · Distortions81

**Go, embedded firmware, game engines, and infrastructure.**

I build software and hardware that I can measure, understand, and improve—from
desktop and browser game engines to microcontroller firmware and services used
in day-to-day operations. My process is simple: build, measure, refine, and document.

## Selected projects

| Project | What I’m building |
| --- | --- |
| [GD-DOOM](https://github.com/Distortions81/GD-DOOM) | A Doom engine and source port in Go for desktop and browser, with GPU drawing that preserves the software-rendered look, classic and modern presentation, and FM, SoundFont, and PC speaker audio. [Play](https://m45sci.xyz/u/dist/GD-DOOM/) |
| [goThoom](https://github.com/Distortions81/goThoom) | A cross-platform client for the classic Clan Lord MMORPG, with modern rendering and audio, session recording, Go scripting, and optional text-to-speech. [Website & downloads](https://gothoom.m45sci.xyz/) |
| [goPine](https://github.com/Distortions81/goPineTime) | PineTime smartwatch firmware in Go and TinyGo: clock, alarms, timers, Bluetooth notifications, and firmware updates with on-watch confirmation and rollback. An active developer project. |
| [M45-goPool](https://github.com/M45Core/M45-goPool) | A solo Bitcoin mining pool written from scratch in Go, with direct Bitcoin Core integration, Stratum/TLS, worker telemetry, a web dashboard, and reproducible benchmarks. [Pool](https://m45core.com/) |
| [StratumStats](https://github.com/M45Core/StratumStats) | Bitcoin mining-pool observability: regional template-delivery timing, median and P95 delay, availability, TLS, and coinbase-derived fee evidence backed by recomputable observations. [Dashboard](https://stratumstats.m45core.com/) |
| [M45-Gamma-Firmware](https://github.com/M45Core/M45-Gamma-Firmware) | ESP32-S3 firmware for Bitaxe Gamma 602 miners, with weighted multi-pool share splitting, ordered backup pools, a live dashboard, web updates, and hardware safety controls. |
| [ChatWire](https://github.com/M45-Science/ChatWire) | Factorio server management and Discord integration: process lifecycle control, chat bridging, moderation, updates, and shared multi-instance operations. |
| [FactMapGen](https://github.com/M45-Science/FactMapGen) | A Go web editor for Factorio map settings, with seeded previews for Nauvis and Space Age planets, exact Factorio rendering, and authenticated, audited presets. [Try it](https://mapgen.m45sci.xyz/) |
